# ☁️ نظام خدام الوحي — النسخة السحابية المشتركة

تطبيق HTML مستقل (مبني على نسختك السابقة) يدعم تسجيل الدخول بحساب منفصل لكل شخص، مدرسة واحدة مشتركة، دعوات للأعضاء، وحفظ البيانات في Supabase مع مزامنة بين الأجهزة.

> **ملاحظة مهمة:** هذا مشروع جاهز للنشر وليس موقعاً منشوراً حالياً. يجب إعداد مشروع Supabase خاص بك ورفع ملفات `site` على استضافة HTTPS. غير تابع للناشر الأصلي لبرنامج Windows.

## 1) إنشاء قاعدة البيانات

1. افتح https://supabase.com وأنشئ مشروعاً جديداً.
2. ادخل إلى **SQL Editor**.
3. افتح ملف `schema.sql` المرفق، انسخ محتواه بالكامل واضغط **Run** *مرة واحدة على مشروع جديد*.
4. ستُنشأ الجداول والصلاحيات والدوال اللازمة. سيمنع **Row Level Security (RLS)** أي حساب لا ينتمي إلى المدرسة من قراءة معلوماتها.

## 2) ربط التطبيق بـ Supabase

1. من لوحة مشروع Supabase انتقل إلى **Project Settings → API** (قد تختلف تسمية القائمة).
2. انسخ **Project URL** و **Publishable key** (أو **anon public key** إن كان هو المتاح).
3. افتح `site/config.js` وبدّل النصوص التجريبية:

   ```js
   window.KHUDDAM_CONFIG = {
     SUPABASE_URL: 'https://your-project.supabase.co',
     SUPABASE_PUBLISHABLE_KEY: 'sb_publishable_xxx'
   };
   ```

**ممنوع وضع `service_role` أو أي secret key في JavaScript أو ملفات الاستضافة العامة.** المفتاح العمومي ليس سرّاً؛ حماية بيانات المدرسة تتم بواسطة RLS والسياسات المرفقة.

## 3) الاستضافة

1. اختر استضافة مجانية للمواقع الثابتة مثل **Netlify**: https://app.netlify.com/drop
2. ارفع مجلد **`site/`** الذي يحتوي على `index.html` و`config.js` فقط. لا ترفع `schema.sql` ولا ملفات النسخ الاحتياطية إلى الموقع.
3. ستحصل على رابط `https://...netlify.app` تستطيع مشاركته مع صاحبك.
4. من Supabase → **Authentication → URL Configuration** ضع رابط الموقع في **Site URL** و **Redirect URLs** حتى تعمل رسائل التأكيد واستعادة كلمة المرور. يمكن إضافة رابط مسار الصفحة إذا احتاج ذلك.
5. في Supabase → **Authentication → Providers → Email** تأكد من تفعيل التسجيل بالبريد الإلكتروني. يُنصح بالإبقاء على تأكيد البريد الإلكتروني.

> الـ SDK في هذا الإصدار يُحمَّل من CDN، لذلك يحتاج اتصالاً بالإنترنت. لا تفتح HTML بـ `file://` لاستخدام النظام السحابي؛ استعمل رابط HTTPS المنشور.

## 4) الاستعمال مع صاحبك

1. افتح رابط الموقع وسجّل حسابك بالبريد وكلمة المرور، وفعّل الإيميل إذا طُلب منك ذلك.
2. اختر **إنشاء مدرسة** وسَمِّها. تصبح تلقائياً **المدير**.
3. من القائمة، افتح **👥 الفريق والحسابات** → **إنشاء كود دعوة**.
4. ابعث الكود لصاحبك **بشكل خاص**. الكود صالح **7 أيام ولشخص واحد**.
5. صاحبك يفتح نفس الرابط، ينشئ حسابه الخاص، ويختار **الانضمام لفريق** مع الكود.
6. الآن تستطيعان إدخال الطلاب والحفظ والحضور والمالية في نفس المدرسة. التغييرات تتزامن تلقائياً. راقب الشارة العلوية: **محفوظ في السحابة**.

**الصلاحيات:** المدير يستطيع دعوة الأعضاء وإزالتهم، والأعضاء المحررون يمكنهم رؤية وتعديل جميع سجلات المدرسة. لا توجد حالياً صلاحيات منفصلة لكل حلقة أو معلم.

## 5) نقل معلوماتك من الإصدار المحلي القديم

إذا كنت تستعمل HTML القديم وبه بيانات حقيقية:

1. افتح **الملف القديم** في نفس المتصفح الذي حفظ فيه البيانات.
2. **الإعدادات والنسخ** → **تنزيل نسخة JSON**.
3. افتح **الموقع الجديد** بعد الدخول إلى المدرسة.
4. **الإعدادات والنسخ** → **استيراد نسخة JSON** واختر الملف.
5. انتظر حتى تصبح الشارة **محفوظ في السحابة**.

> الاستيراد واستعمال البيانات التجريبية و«حذف الكل» **يؤثر على المدرسة كاملة وعلى جميع أعضائها** وليس على جهاز واحد فقط. استخرج نسخة JSON قبل الخطوات الكبيرة.

## 6) ملاحظات تقنية وأمنية

- حسابات Supabase Auth (بريد إلكتروني وكلمة مرور)، وسياسات RLS مفعّلة على الجداول.
- التحديث يتم عبر `Postgres Changes` مع تحقق احتياطي كل 20 ثانية عند الاتصال.
- يوجد رقم مراجعة للسجلات لمنع الكتابة فوق تحديثات جهاز آخر من غير اكتشافها. يجري دمج التغييرات غير المتعارضة في الواجهة، وعند التعديل على نفس الحقل يظهر تأكيد.
- الحفظ **سحابي فقط**؛ في حال انقطاع الإنترنت لا تعتبر البيانات محفوظة حتى تظهر شارة الحفظ. تجنب إغلاق الصفحة قبل اكتمال المزامنة.
- تبقى النسخ JSON وCSV متاحة للنسخ الاحتياطي والتحليل.
- هذا النموذج مناسب لفريق صغير. إن كبر عدد المستخدمين والعمليات، يفضّل توزيع السجلات على جداول منفصلة وإضافة سجل تدقيق وصلاحيات تفصيلية.
- بما أنّه يحتوي بيانات طلاب وأولياء، استعمل كلمات مرور قوية وشارك الأكواد بشكل خاص والتزم بالمتطلبات المحلية لحماية البيانات.

## محتويات الحزمة

- `site/index.html` — الواجهة العربية كاملة.
- `site/config.js` — إعدادات الاتصال العامة التي تحتاج تعديلها.
- `schema.sql` — قاعدة البيانات والأمان والمزامنة.
- `README.md` — هذا الدليل.
